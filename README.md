# PDF Editor

Açıq mənbəli bir PDF görüntüləyici və redaktoru. Bu tətbiq, istifadəçilərin PDF sənədlərini görüntüləmələrinə, üzərində fiqurlar çəkmələrinə və mətnlərə əlavə etmələrinə imkan verir. 

## Xüsusiyyətlər

- PDF sənədini görüntüləmə
- Fiqurlar çəkmək və redaktə etmək
- Şəkillər əlavə etmək
- Mətn əlavə etmək



### Tələb olunanlar

- Node.js (versiya 14 və ya yuxarı)
- NPM (Node Package Manager)

### Proyekti quraşdırmaq

1. Repositoriyanı yerli mühitinizə klonlayın:

   ```bash
   git clone https://github.com/ilkinsufi/pdf-editor.git
   cd pdf-editor
   npm install
   npm run dev
   ```
4.	Brauzerinizdə açın: http://localhost:3000
